Curve Fitter

点の並びを見て、いちばんフィットする線を引くゲーム。本物の回帰式(最小二乗法)との近さでスコアが決まります。直線・二次関数・対数関数・指数関数に挑戦できます。

A game where you draw the line that best fits a set of points. Your score depends on how close you get to the true least-squares regression line.
